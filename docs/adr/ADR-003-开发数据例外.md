# ADR-003：初始开发阶段的 devdata 例外

- 状态：Superseded
- 日期：2026-10-05（当日撤销）

> 撤销说明：用户同日决定改回原严格规则（真实个人数据永不进入 git）。多设备开发的数据同步改由非 git 方式解决（如用同步盘同步本地 `~/Lifebase/`，或手动传输）。devdata/ 目录已删除，本 ADR 仅作决策历史保留。

2026-10-06 的独立私有数据仓库授权见
[ADR-017](ADR-017-独立私有数据仓库与无损迁移.md)。它不恢复本 ADR 的代码仓库
devdata 方案；以下内容保留为当时决策历史。

## 决策

初始开发阶段允许把少量开发用数据（含少量真实数据，如截断的聊天记录导出）放入 `devdata/` 目录，提交到 **Private** GitHub 仓库，以支持用户的多设备开发。数据根 `~/Lifebase/` 仍然永不提交。

## 理由

- 用户在多台设备上开发，需要测试数据随仓库同步。
- 初始阶段仓库必然私有，泄露面可控。

## 约束（不可违反）

1. 仓库必须保持 **Private**；devdata 含真实数据期间绝不公开。
2. 只提交**最小样本**（截断导出、少量对话），禁止完整数据库/全量媒体；单文件 < 100MB。
3. 合成/脱敏优先；真实数据仅在复现问题必要时提交。
4. 测试与 CI 不得依赖 devdata（用 `tests/fixtures/`）。
5. **公开开源前的硬性门槛**：删除 devdata 真实数据 + 清理 git 历史（git-filter-repo 或重建仓库），由用户本人确认后方可公开。

## 撤销条件

满足以下任一条件时，本例外自动撤销，恢复 docs/context.md §26 的严格禁令：

- 仓库准备公开/开源；
- 用户宣布初始开发阶段结束。

撤销方式：删除 devdata/ 真实内容 → 清理 git 历史 → 恢复 .gitignore 严格模式 → 本 ADR 标记 Superseded。
